# Mario Ojeda — ENC 1102 ePortfolio

Static ePortfolio for ENC 1102 at the University of Central Florida.

## Updating the portfolio

Edit `index.html` for content, `styles.css` for appearance, and `app.js` for navigation behavior. Push changes to the `main` branch; GitHub Pages will publish the updated version automatically.

The public site does not require a login. Unfinished coursework is intentionally marked with clear placeholders so it can be added throughout the semester.
